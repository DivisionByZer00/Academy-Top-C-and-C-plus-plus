#### Решения домашних заданий "Языки программирования С и С++"

## Homework 01

### Тема: "C++ core. Консольная проверка готовности устройства"

**Задача**    
Создайте консольную программу mission_console, которая определяет, готово ли учебное устройство к запуску.

**Программа должна получить:**
- имя устройства;
- текущий заряд от 0 до 100;
- планируемый расход энергии, не меньше 0;
- количество успешно пройденных проверок от 0 до 3

Устройство готово, если одновременно выполнены два условия:
1. После задачи останется не меньше 25%.
2. Пройдены все 3 проверки.

Что сделать

**Задание 1 Подготовить проект**    
Создайте папку:    
*mkdir -p ~/cpp-course/lesson-1/homework    
cd ~/cpp-course/lesson-1/homework*    
Создайте файл main.cpp.    
**Минимальные требования:**
- подключены <iostream> и <string>;
- нет using namespace std;;
- правило минимального остатка записано как const int minimumReserve{25};;
- все локальные числа получают начальное значение;
- есть минимум три функции, включая main.

**Задание 2. Реализовать функции**    
**Функция расчета остатка:**    
*int calculateRemainingBattery(int battery, int plannedConsumption);*    
**Она возвращает выражение:**    
*battery - plannedConsumption*    
**Функция проверки готовности:**    
*bool isReadyForMission(    
int remainingBattery,    
&nbsp; int successfulChecks,    
int minimumReserve    
);*    
Она возвращает true, только если остаток не меньше минимума и число успешных проверок равно 3    
**Функция вывода статуса:**    
*void printStatus(bool ready);*    
**Она выводит:**
- Status: ready для true;
- Status: not ready для false.    
Синтаксис объявления функции, параметры, круглые скобки, запятые и завершающая точка с запятой разобраны в основном уроке. Новым
является тип void: он означает, что функция выполняет действие, но не возвращает значение.

**Задание 3. Проверить входные данные**    
Если выполняется хотя бы одно условие:
- заряд меньше 0 или больше 100;
- расход меньше 0;
- количество проверок меньше 0 или больше 3;

**программа должна вывести:**    
*Input error*    
**и завершиться через:**    
*return 1;*  
Для корректных данных программа завершается через return 0;.    
Пока предполагаем, что пользователь вводит числа, а не текст вместо числа. Проверка состояния std::cin появится в отдельной теме.

**Задание 4. Вывести отчет**    
**Для корректных данных выведите:**    
*Device: <имя>    
Remaining battery: <остаток>%    
Checks passed: <число>/3    
Status: ready*    
или:    
*Status: not ready*    
Эти строки показывают ожидаемый вывод программы, а не C++-код.

**Задание 5. Собрать программу**    
Используйте:    
*g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o mission_console    
mission_console*    
Запустите:    
*./mission_console*    
В финальной версии не должно быть ошибок и предупрежд
