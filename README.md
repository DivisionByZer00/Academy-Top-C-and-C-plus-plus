**Задача**    
Создайте консольную программу mission_console, которая определяет, готово ли учебное устройство к запуску.

Устройство готово, если одновременно выполнены два условия:
1. После задачи останется не меньше 25%.
2. Пройдены все 3 проверки.

**Она выводит:**
- Status: ready для true;
- Status: not ready для false.    
Синтаксис объявления функции, параметры, круглые скобки, запятые и завершающая точка с запятой разобраны в основном уроке. Новым

**Программа должна получить:**
- имя устройства;
- текущий заряд от 0 до 100;
- планируемый расход энергии, не меньше 0;
- количество успешно пройденных проверок от 0 до 3

**Правила бонуса:**
1. Для первого устройства бонус считают через копию. Исходный заряд не должен измениться.
2. Для второго устройства бонус применяют через ссылку. Исходный заряд должен вырасти на 20.
3. Отчет печатается через константные ссылки и не имеет права менять значения.

**Что сделать**

**Задание 1. Подготовить проект**    
**Создайте папку:**    
*mkdir -p ~/cpp-course/lesson-2/homework

- нет using namespace std;
- бонус записан как const int bonus{20};
- все локальные числа получают начальное значение;
- есть минимум четыре функции, включая main.

**Задание 2. Реализовать функции**    
**Функция копии:**    
*int applyBonusCopy(int battery, int bonus);*    
Она возвращает battery + bonus и не меняет объект вызывающей стороны, потому что параметр приходит по значению.    
**Функция изменения:**    
*void applyBonusReference(int& battery, int bonus);*    
**Она выполняет:**    
*battery += bonus;*    
**Функция печати одного устройства:**    
*void printDevice(const std::string& name, const int& battery);*    
**Она выводит:**    
*< имя >: < заряд >%*    
**Функция печати пары:**    
*void printReport(    
&nbsp;&nbsp;&nbsp;&nbsp;const std::string& firstName,    
&nbsp;&nbsp;&nbsp;&nbsp;const int& firstBattery,    
&nbsp;&nbsp;&nbsp;&nbsp;const std::string& secondName,    
&nbsp;&nbsp;&nbsp;&nbsp;const int& secondBattery    
);*

**Задание 3. Проверить входные данные**    
**Программа читает:**
- имя первого устройства;
- заряд первого устройства;
- имя второго устройства;
- заряд второго устройства.

**Если хотя бы один заряд меньше 0 или больше 100, программа должна вывести:**
*Input error*    
**и завершиться через:**    
*return 1;*    
Для корректных данных программа завершается через return 0;.    
Пока предполагаем, что пользователь вводит числа, а не текст вместо числа.

**Задание 4. Вывести отчет**    
Для корректных данных сначала напечатайте исходные значения, затем примените бонусы, затем напечатайте итог.    
**Ожидаемый вид:**    
*Before:    
Alpha: 50%    
Beta: 30%    
Copy result: 70%    
After:    
Alpha: 50%    
Beta: 50%*    
Строки являются примером вывода, а не C++-кодом. Имена берутся из ввода. Copy result показывает значение, которое вернула функция копии. Само Alpha при этом остается прежним.

**Задание 5. Собрать программу**

*g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o energy_console*    
Запустите:    
*./energy_console*    
В финальной версии не должно быть ошибок и предупреждений.

## Homework 03

### Тема: "Указатели. Консоль выбора датчика"

**Задача**    
Создайте консольную программу sensor_console. Она хранит заряды двух устройств и один указатель-датчик.

**Команды пользователя:**
- 1 направить датчик на первое устройство;
- 2 направить датчик на второе устройство;
- 0 отключить датчик;
- любое другое число считать ошибкой ввода.

После выбора программа печатает состояние датчика. Если датчик включен, она дополнительно увеличивает выбранный заряд на 5 через указатель.

**Что сделать**

**Задание 1. Подготовить проект**    
**Создайте папку:**    
*mkdir -p ~/cpp-course/lesson-3/homework    
cd ~/cpp-course/lesson-3/homework*    
**Минимальные требования:**
- подключен < iostream >;
- нет using namespace std;;
- указатель всегда инициализирован;
- есть функция печати через const int*;
- есть функция выбора датчика.

**Задание 2. Реализовать функции**    
**Функция копии:**    
*ivoid printThroughSensor(const int* sensor);*    
**Правила вывода:**
- при nullptr напечатать Sensor offline;
- иначе напечатать Telemetry: < заряд >%.

**Выбор датчика:**  
*int* selectSensor(int command, int& firstBattery, int& secondBattery);*    
**Правила возврата:**
- 1 вернуть адрес первого заряда;
- 2 вернуть адрес второго заряда;
- 0 вернуть nullptr;
- другое число тоже вернуть nullptr.

Новым является возврат указателя из функции. Это не возврат ссылки на локальную переменную: функция возвращает адрес объекта, который живет в main.    
**После успешного выбора 1 или 2 в main выполните:**    
**sensor += 5;*    
Для 0 и ошибки ввода заряд менять нельзя.

**Задание 3. Проверить входные данные**    
**Программа читает:**
- заряд первого устройства;
- заряд второго устройства;
- команду 0, 1 или 2.

Если хотя бы один заряд меньше 0 или больше 100, выведите Input error и завершитесь через return 1;.    
Если команда не равна 0, 1 или 2, выведите Input error и завершитесь через return 1;. При этом заряд через указатель не меняйте.    
Если после надбавки 5 заряд стал больше 100, тоже выведите Input error и верните 1.

**Задание 4. Вывести отчет**    
Для корректной команды 1 или 2 ожидаемый вид:    
*First: 40%    
Second: 20%    
Telemetry: 45%*    
Здесь первое устройство было 40, команда 1 направила датчик на него и добавила 5.    
**Для команды 0:**    
*First: 40%    
Second: 20%    
Sensor offline*    
Строки являются примером вывода, а не кодом.

**Задание 5. Собрать программу**    
**Используйте:**    
*g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o    
sensor_console    
./sensor_console*

**Задание 6. Провести минимум четыре проверки**
| Проверка | Заряд 1 | Заряд 2 | Команда | Ожидаемая телеметрия | Итог 1 | Итог 2 |
|:---------|:--------|:--------|:--------|:---------------------|:-------|:-------| 
| 1 | 40 | 20 | 1 | Telemetry: 45% | 45 | 20 |
| 2 | 40 | 20 | 2 | Telemetry: 25% | 40 | 25 |
| 3 | 40 | 20 | 0 | Sensor offline | 40 | 20 |
| 4 | 40 | 20 | 7 | Input error | 40 | 20 |

Для каждой проверки запишите ожидание, факт и совпадение. В проверке 4 код возврата должен быть 1.

## Homework 04

### Тема: "Куча. Резерв по запросу"

**Задача**    
Создайте консольную программу reserve_console. Она читает текущий заряд и флаг, нужен ли дополнительный резерв.

**Правила:**
1. Если флаг равен 0, кучу не выделять. Напечатать только текущий заряд и строку No extra reserve.
2. Если флаг равен 1, выделить new int{20}, прибавить это значение к заряду в отчете, затем освободить память.
3. Любой другой флаг, заряд вне 0-100 или сумма выше 100 дают Input error и код возврата 1.
4. Если резерв выделяли, к моменту успешного или ошибочного завершения после выделения память должна быть возвращена.

**Что сделать**

**Задание 1. Подготовить проект**    
Создайте папку:    
*mkdir -p ~/cpp-course/lesson-4/homework    
cd ~/cpp-course/lesson-4/homework*    
**Минимальные требования:**
- подключен < iostream >;
- нет using namespace std;;
- указатель инициализирован nullptr;
- delete вызывается только если указатель не nullptr;
- после delete указатель снова nullptr.

**Задание 2. Реализовать функции**    
**Функция копии:**    
*int* makeExtraReserve();*    
Она возвращает результат new int{20}.    
**Функция очистки:**    
*void releaseExtraReserve(int*& extra);*    
Она делает delete extra; и extra = nullptr;, если указатель не пустой.    
Параметр имеет тип int*&, потому что функция должна обнулить именно указатель вызывающей стороны, а не его копию.    
Это новая комбинация уже известных идей: ссылка на указатель. int* хранит адрес запаса, & после типа позволяет изменить сам указатель в main.

**Задание 3. Проверить входные данные**    
**Программа читает:**
- заряд от 0 до 100;
- флаг 0 или 1.

**Неверный диапазон дает:**    
*Input error*    
и return 1;. Если к этому моменту резерв уже выделяли, сначала вызовите очистку.

**Задание 4. Вывести отчет**    
**Для заряда 70 и флага 1:**    
*Battery: 70%    
Extra: 20%    
Total: 90%    
Buffer released*    
Для заряда 70 и флага 0:    
*Battery: 70%    
No extra reserve*    
Для заряда 90 и флага 1 сумма равна 110. Нужен Input error и возврат памяти, если new уже выполнили.

**Задание 5. Собрать программу**
*g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o    
reserve_console    
./reserve_console**

**Задание 6. Провести минимум четыре проверки**
| Проверка | Заряд | Флаг | Ожидание |
|:---------|:------|:-----|:---------|
| 1 | 70 | 1 | Total 90, есть Buffer released |
| 2 | 70 | 0 | No extra reserve, без Extra |
| 3 | 90 | 1 | Input error, память возвращена |
| 4 | 120 | 1 | Input error new, лучше не вызывать |

В проверке 4 безопаснее сначала проверить заряд и не выделять кучу. Запишите, какой порядок вы выбрали и почему.

**Задание 7. Диагностический эксперимент**    
Временно закомментируйте delete в releaseExtraReserve и запустите проверку 1. Программа может выглядеть «живой». Запишите, почему
это все равно утечка. Верните delete.
